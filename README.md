# 🎧 Simulador de Diagnóstico e Atendimento de Conectividade (Suporte N1)

Projeto prático focado em triagem de incidentes de rede, atendimento humanizado ao usuário final e documentação de fluxo de resolução de chamados[cite: 8].

## 🎯 Objetivos
- Simular o fluxo de atendimento de Suporte Técnico Nível 1 para problemas recorrentes de conectividade (IP inválido, falha de DNS e lentidão Wi-Fi)[cite: 8].
- Padronizar checklists técnicos de diagnóstico e mensagens em linguagem acessível ao cliente final[cite: 8].
- Gerar registros estruturados de chamados (`chamados_n1.txt`) para histórico e rastreabilidade[cite: 8].

## 📂 Estrutura do Projeto
- `simulador_n1.py`: Script interativo em Python para simulação de triagem e registro de chamados.
- `roteiro_atendimento.md`: Playbook de atendimento N1 com fluxo de solução e comunicação com o usuário[cite: 8].
- `chamados_n1.txt`: Histórico gerado automaticamente durante os testes de atendimento.
